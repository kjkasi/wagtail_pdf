# Анализ влияния: переработка PDF-просмотрщика

## Цель изменения

1. Полностью удалить редакторские комментарии и связанные данные.
2. Увеличить просмотрщик почти до размеров окна.
3. Зафиксировать панель навигации, чтобы кнопки не смещались при смене страницы.
4. Добавить масштабирование.
5. Показывать встроенные в PDF аннотации средствами PDF.js.
6. Разобраться с ошибкой загрузки PDF при доступе к `runserver` с другого компьютера.

## Затрагиваемые модули и их контракты

### `catalog/models.py`

**Назначение:** хранение страниц каталога, связи с Wagtail Document и проверка PDF.

**Вызывающие компоненты:** Wagtail Admin, шаблоны страниц, `create_demo`, серверные и браузерные тесты.

**Контракты, которые нужно сохранить:**

- загружается только корректный PDF;
- `page_count` соответствует реальному числу страниц;
- опубликованный документ остаётся доступен в публичном каталоге;
- удаляется только контракт `PdfDocumentPage -> PageComment`.

### `catalog/static/catalog/js/pdf-viewer.js`

**Назначение:** загрузка PDF.js, рендер текущей страницы, очередь переходов и управление навигацией.

**Вызывающий компонент:** `catalog/templates/catalog/pdf_document_page.html`.

**Контракты, которые нужно сохранить:**

- страница не выходит за границы документа;
- быстрые нажатия не приводят к показу устаревшего результата;
- canvas и индикатор страницы обновляются атомарно;
- ошибки загрузки и рендеринга видны пользователю;
- worker и PDF загружаются с того же origin.

### Шаблон и стили просмотрщика

- `catalog/templates/catalog/pdf_document_page.html`
- `catalog/static/catalog/css/catalog.css`

Они задают DOM-контракт через `data-*` атрибуты. Изменение затронет browser smoke-тест и JS-селекторы.

Пробелы:

- нет PDF-фикстуры со встроенными аннотациями;
- нет проверки annotation layer и безопасных ссылок;
- нет тестов масштаба и его границ;

- нет smoke-теста через LAN-адрес или эквивалентный non-localhost origin;
- нет проверки удаления данных `PageComment` миграцией.

## Сетевой симптом

Локально проверено обращение к dev-серверу по адресу `http://192.168.1.189:8000`:

- HTML страницы — `200`;
- PDF endpoint `/documents/...pdf` — `200 application/pdf`;
- PDF.js worker и модули — `200`;
- canvas появился в Chromium.

В консоли есть предупреждение о том, что заголовок `Cross-Origin-Opener-Policy` игнорируется для недоверенного HTTP-origin. В проведённой проверке оно не блокирует PDF. Поэтому нельзя считать `ALLOWED_HOSTS`, media routing или COOP доказанной первопричиной. Нужны точный текст ошибки, версия браузера и Network log с компьютера, где возникает сбой.

## Риск: высокий

Изменение затрагивает основной пользовательский сценарий и включает намеренное удаление таблицы с данными комментариев. Annotation layer и zoom меняют общий цикл рендеринга, а сетевая ошибка пока не воспроизводится на машине разработки.

## Рекомендация

Продолжить по отдельным вертикальным шагам: сначала зафиксировать новые тестовые ожидания и резервное копирование данных, затем удалить комментарии, стабилизировать раскладку, добавить zoom, после этого annotation layer и в конце закрыть сетевую ошибку по воспроизводимому сценарию. Не объединять неизвестную сетевую причину со случайным изменением настроек.
